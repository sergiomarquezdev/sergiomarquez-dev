# Security Policy

## Reporting a vulnerability

Please report security issues privately, not through public issues:

- GitHub: use **Report a vulnerability** under the repository's Security tab (private vulnerability reporting is enabled).
- Email: contacto@sergiomarquez.dev

Include the affected URL or file, the steps to reproduce and the impact you expect. I aim to reply within a week.

## Scope

This repository builds the static site served at https://sergiomarquez.dev. Only the latest deployment on `main` is supported.
